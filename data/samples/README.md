# Sample images

Electron-microscopy cross-sections of myelinated axons, used as test data for
g-ratio computation. Extracted from the source PowerPoint provided by the
project owner.

| File | Size (px) | Notes |
|------|-----------|-------|
| `sample_01.png` | 803 × 604 | One large central axon with **malformed / non-hermetic myelin** (loose, broken wrapping on the left), plus several partial axons. Scale bar: 200 nm. |
| `sample_02.png` | 871 × 844 | Single axon with thick, well-formed multilayered myelin; roughly polygonal outline. Scale bar present (bottom-right). |
| `sample_03.png` | 482 × 505 | Multiple smaller axons with thinner myelin; touching/clustered fibers. |

All images are grayscale EM; myelin appears as dark concentric lamellae, the
axoplasm (axon interior) as a lighter region enclosed by the myelin, and the
extracellular space as the lighter background.
